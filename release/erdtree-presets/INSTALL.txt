erdtree presets: 8 synth patches for the erdtree engine (Hundekraft Workshop 3.0).

Install the erdtree plugin first (erdtree.knl, under Your plugins in the workshop).
Enter disk mode on the OP-1: hold Shift and press COM, then press T3.
Open synth/ in this folder and copy the erdtree folder into the OP-1 disk's synth/ folder,
so the files end up in synth/erdtree/ (for example synth/erdtree/first grace.aif). Then eject.
The OP-1 restarts by itself, syncs the new files and waits for a key press.
To play them: in synth mode hold Shift and press a sound key (1 to 8),
turn blue to the erdtree folder and green to the preset.

The OP-1 keeps 300 user synth presets in total, including the ones already on it.
If the sync goes over that, it silently drops the extra presets.
An existing patch with the same file name may keep its old sound after the sync; rename the file to replace it.
